==============================================================
 WP Components: Slider
==============================================================

Кастомный ползунок (Range Slider) с поддержкой 1 или 2 бегунков.
Построен на чистом JS + Tailwind, без тяжелых сторонних библиотек.

--------------------------------------------------------------
 1. ГЛАВНЫЕ ФИЧИ
--------------------------------------------------------------
 - АВТО-РЕЖИМ: Передайте число для 1 бегунка, или массив [min, max] 
   для 2 бегунков. Компонент сам всё поймет!
 - БУЛЛИТЫ (PINS): При наведении или перетаскивании над бегунком 
   появляется подсказка с текущим значением.
 - ФОРМАТИРОВАНИЕ: Легко добавляйте валюту или проценты с помощью 
   пропсов prefix и suffix.
 - ТОЧНОЕ ПОЗИЦИОНИРОВАНИЕ: Бегунки не вылезают за края полосы 
   ни на пиксель даже при минимальных и максимальных значениях.
 - ИНТЕГРАЦИЯ С ФОРМАМИ: Автоматически создает скрытые <input> 
   для отправки данных на сервер.

--------------------------------------------------------------
 2. ДОСТУПНЫЕ АТРИБУТЫ (Props)
--------------------------------------------------------------
 min      (int)    : Минимальное значение. По умолчанию: 0
 max      (int)    : Максимальное значение. По умолчанию: 100
 step     (int)    : Шаг изменения. По умолчанию: 1
 value    (int|array) : Текущее значение. Число для 1 бегунка, 
                        массив [minVal, maxVal] для 2 бегунков.
 name     (string) : Базовое имя для скрытого input. По умолчанию: 'slider_value'
 showPins (bool)   : Показывать ли буллиты со значением. По умолчанию: true
 prefix   (string) : Текст ДО числа (например, '$'). По умолчанию: ''
 suffix   (string) : Текст ПОСЛЕ числа (например, ' ₽' или '%'). По умолчанию: ''
 class    (string) : Дополнительные Tailwind классы для обертки

--------------------------------------------------------------
 3. ПРИМЕРЫ ИСПОЛЬЗОВАНИЯ (PHP)
--------------------------------------------------------------

 // Одиночный ползунок (например, громкость)
 render_component('ui.Slider', [
     'min'    => 0,
     'max'    => 100,
     'step'   => 5,
     'value'  => 50,
     'suffix' => '%',
     'name'   => 'volume'
 ]);

 // Двойной ползунок (например, фильтр цен в магазине)
 render_component('ui.Slider', [
     'min'      => 0,
     'max'      => 50000,
     'step'     => 100,
     'value'    => [1000, 25000], // Массив включает режим 2 бегунков!
     'name'     => 'price',
     'prefix'   => '',
     'suffix'   => ' ₽',
     'showPins' => true,
     'pinAlways' => true //  Пины всегда на месте
 ]);

 // Фильтр цен с доступностью
render_component('ui.Slider', [
    'min'   => 0,
    'max'   => 50000,
    'value' => [1000, 25000],
    'name'  => 'price',
    'suffix' => ' ₽',   
    
    // КАСТОМНЫЕ АТРИБУТЫ:
    'id' => 'price-range-slider',               // Уникальный ID
    'aria-label' => 'Фильтр по цене',            // Для скринридеров
    'data-controller' => 'filter-slider',        // Для Stimulus/Alpine
]);

// Фильтр пробега
render_component('ui.Slider', [
    'min'   => 0,
    'max'   => 300000,
    'value' => [50000, 150000],
    'name'  => 'mileage',
    'suffix' => ' км',
    
    // Другой ID и ARIA
    'id' => 'mileage-range-slider',
    'aria-label' => 'Фильтр по пробегу',
]);

 // Использование через шорткат
 slider(['max' => 1000, 'value' => [100, 800], 'prefix' => '$']);

--------------------------------------------------------------
 4. ТЕХНИЧЕСКИЕ ДЕТАЛИ (Для разработчика)
--------------------------------------------------------------
 - При одиночном режиме создается <input type="hidden" name="slider_value">
 - При двойном режиме создается два инпута:
   <input type="hidden" name="slider_value_min">
   <input type="hidden" name="slider_value_max">
   (Имена зависят от пропса 'name').
 - События touch поддерживаются из коробки (работает на мобилках).
 - Бегунки можно перетаскивать клавиатурой (Tab + стрелки).
