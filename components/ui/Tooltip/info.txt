==============================================================
 WP Components: Tooltip
==============================================================

Легковесный тултип, работающий на основе data-атрибутов.
Не требует оборачивания в PHP-компонент. Просто добавьте
атрибут data-tooltip к любому HTML элементу!

Поддерживает появление при наведении мыши (hover) 
и при фокусе с клавиатуры (focus).

--------------------------------------------------------------
 1. ИСПОЛЬЗОВАНИЕ
--------------------------------------------------------------
Добавьте атрибут data-tooltip к нужному элементу:

 <button data-tooltip="Это всплывающая подсказка">
     Наведи на меня
 </button>

--------------------------------------------------------------
 2. ПОЗИЦИОНИРОВАНИЕ
--------------------------------------------------------------
Используйте атрибут data-tooltip-position:

 <button data-tooltip="Сверху" data-tooltip-position="top">Top</button>
 <button data-tooltip="Снизу" data-tooltip-position="bottom">Bottom</button>
 <button data-tooltip="Слева" data-tooltip-position="left">Left</button>
 <button data-tooltip="Справа" data-tooltip-position="right">Right</button>

По умолчанию используется позиция "top", если атрибут 
data-tooltip-position не указан.

--------------------------------------------------------------
 3. КАК ЭТО РАБОТАЕТ
--------------------------------------------------------------
Скрипт автоматически находит все элементы с data-tooltip
на странице и динамически создает подсказки при наведении.
Стили подключаются через CSS файл компонента.
