==============================================================
 WP Components: Toast (аналог Sonner)
==============================================================

Важно: Для работы тостов необходимо добавить контейнер в тему.
Добавьте в header.php или footer.php:
   <?php render_component('ui.Toast'); ?>


--------------------------------------------------------------
 1. НАСТРОЙКА КОНТЕЙНЕРА (PHP)
--------------------------------------------------------------
render_component('ui.Toast', [
    'position' => 'bottom-right',  // Позиция на экране
    'class'    => '',              // Дополнительные Tailwind классы
]);

Доступные позиции:
 - top-left
 - top-center
 - top-right
 - bottom-left
 - bottom-center
 - bottom-right (по умолчанию)


--------------------------------------------------------------
 2. ВЫЗОВ ИЗ JAVASCRIPT (Клиентская сторона)
--------------------------------------------------------------
Сигнатура: window.toast(message, options)

Примеры:

// Простое уведомление (success по умолчанию)
window.toast('Сохранено успешно!');

// С ошибкой и описанием
window.toast('Ошибка сети', {
    type: 'error',
    description: 'Проверьте подключение к интернету'
});

// С действием (Action)
window.toast('Комментарий удален', {
    type: 'warning',
    action: {
        label: 'Отменить',
        onClick: () => { console.log('Отменяем!') }
    }
});

// Бесконечный тост (не исчезнет сам)
window.toast('Идет загрузка...', {
    type: 'info',
    duration: 0
});

Доступные ключи options (JS):
 - type:        'success' | 'error' | 'warning' | 'info'
 - description: 'Текст под заголовком'
 - duration:    4000 (в миллисекундах, 0 = не исчезает)
 - action:      { label: 'Текст кнопки', onClick: () => {} }
 - className:   'Дополнительные Tailwind классы для тоста'


--------------------------------------------------------------
 3. ВЫЗОВ ИЗ PHP (Серверная сторона, Flash-сообщения)
--------------------------------------------------------------
Используйте хелпер set_flash_toast() перед редиректом.
Сигнатура идентична JS: set_flash_toast($message, $options)

Примеры:

// Простое
set_flash_toast('Настройки обновлены!');

// С параметрами (КЛЮЧИ АБСОЛЮТНО ТАКИЕ ЖЕ КАК В JS)
set_flash_toast('Файл слишком большой', [
    'type'        => 'error',
    'description' => 'Максимальный размер 2MB',
    'duration'    => 10000
]);

Доступные ключи options (PHP):
 - type:        'success' | 'error' | 'warning' | 'info'
 - description: 'Текст под заголовком'
 - duration:    4000
 - className:   'Дополнительные Tailwind классы'
 (action поддерживается только из JS, так как требует callback функцию)
