==============================================================
 WP Components: Button
==============================================================

Универсальный компонент кнопки, поддерживающий вариации,
размеры, состояния и рендеринг в виде ссылки (<a>).

--------------------------------------------------------------
 1. ДОСТУПНЫЕ АТРИБУТЫ (Props)
--------------------------------------------------------------
При передаче в компонент используйте следующие ключи:

 label     (string)  : Текст кнопки. По умолчанию: ''
 variant   (string)  : Визуальный стиль. По умолчанию: 'default'
 size      (string)  : Размер кнопки. По умолчанию: 'default'
 href      (string)  : Если указан, рендерится тег <a> вместо <button>
 disabled  (bool)    : Неактивное состояние. По умолчанию: false
 class     (string)  : Дополнительные Tailwind классы (обрабатывается cn())
 type      (string)  : HTML-атрибут type (button, submit, reset). По умолчанию: 'button'
 onclick   (string)  : JS-обработчик клика (onclick="...")
 children  (string)  : Вложенный контент (HTML строка). Передается вторым аргументом!
                         ИМЕЕТ ПРИОРИТЕТ над label.

--------------------------------------------------------------
 2. ВАРИАНТЫ (variant)
--------------------------------------------------------------
 default     : Темный фон (bg-slate-900)
 destructive : Красный фон (bg-red-500) для опасных действий
 outline     : Прозрачный фон с обводкой
 secondary   : Светлый фон (bg-slate-100)
 ghost       : Без фона и обводки, появляется при ховере
 link        : Выглядит как текстовая ссылка

--------------------------------------------------------------
 3. РАЗМЕРЫ (size)
--------------------------------------------------------------
 default : Стандартная (h-10 px-4)
 sm      : Маленькая (h-9 px-3)
 lg      : Большая (h-11 px-8)
 icon    : Квадратная для иконок (h-10 w-10)

--------------------------------------------------------------
 4. ПРИМЕРЫ ИСПОЛЬЗОВАНИЯ (PHP)
--------------------------------------------------------------

// 1. Простая кнопка
render_component('ui.Button', ['label' => 'Нажми меня']);

// 2. Кнопки разных вариантов и размеров
render_component('ui.Button', [
    'label'   => 'Удалить', 
    'variant' => 'destructive',
    'size'    => 'sm'
]);

// 3. Кнопка-ссылка (рендерит <a href="...">)
render_component('ui.Button', [
    'label' => 'Перейти в корзину',
    'href'  => '/cart'
]);

// 4. Неактивная кнопка
render_component('ui.Button', [
    'label'    => 'Сохранить',
    'disabled' => true
]);

// 5. Кнопка с иконкой (через children)
// Используем функцию component() для вложенности
 $icon = '<svg class="w-4 h-4" viewBox="0 0 24 24" fill="none" stroke="currentColor"><path d="M12 5v14M5 12h14"/></svg>';
render_component('ui.Button', 
    ['variant' => 'outline', 'size' => 'icon'], 
    $icon
);

// 6. Кнопка с иконкой и текстом (через children)
render_component('ui.Button', 
    ['variant' => 'secondary'], 
    $icon . '<span>Добавить</span>'
);

--------------------------------------------------------------
 5. ШОРТКАТЫ
--------------------------------------------------------------
Вы также можете использовать функцию button():

// Простая
button(['label' => 'Клик']);

// С children
button(['variant' => 'ghost'], 'Выйти');
